This function performs facet enumeration. It implements Algorithm of [Yang2025]. User will provide vertex matrix (represent vertex in row), and the function will return facet expressions in inequality constraints. Several examples are included. Users can uncommment any example and run the program to get the result.

Users may change the code, but the copywight will still belong to Y. Yang. If any report/publication is based on this code,  the authors should acknowledge the use and cite [Yang2025].

References:
